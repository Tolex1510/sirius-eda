# Подключение ассистента: результаты 18.11.2026

## Реально подключено

- Существующая Ollama в WSL ПК с Хоши: Qwen `qwen2.5:3b-instruct-q5_K_M` и `bge-m3:latest`. Новые модели не скачивались, сервисы Хоши не менялись.
- Docker SSH-сервис `ollama-remote`, доступен только в Compose-сети. API и worker используют его как общий endpoint.
- Индекс pgvector: 53 источника (48 блюд, 5 разделов справки), 1024 измерения. Первичная индексация заняла 19,91 с; после добавления категорий переиндексированы 48 блюд за 18,5 с.
- Семантический поиск есть в SPA и публичной SSR-витрине. Исходный HTML витрины содержит блюда; клиентский поиск не переводит первоначальную загрузку меню в CSR.

## Исправлено по результатам проверки

- Устранён HTTP 403 при проходе через SSH: API передаёт локальный Host, ожидаемый Ollama. HTTP-прокси среды отключён в клиенте модели.
- Поиск использует актуальные цену, доступность, маркеры рецептуры и категорию поверх cosine ranking; добавлено усиление совпадений слов.
- Отсутствие внешнего Payment у внутренней оплаты больше не трактуется как отсутствие оплаты.
- Модель иногда выбирала не самый новый заказ из нескольких строк контекста. Запрос последнего/указанного заказа теперь обрабатывается детерминированно с фильтром user_id; модель не генерирует номер, сумму и статусы. Чужой номер даёт ответ «Такого заказа нет среди ваших заказов».

## Практические ограничения

Компьютер с Хоши должен быть включён. SSH-сервис переподключается при обрыве, но после перезагрузки ноутбука нужно разблокировать SSH-ключ и обновить путь агента через `scripts/ollama_tunnel.sh start`. Ответы модели проверены на нескольких примерах, они могут ошибаться; факты о заказах защищены отдельным серверным маршрутом внутри ассистента. Семантика учитывает рецепт, а не гарантированное отсутствие следов аллергенов.

Настройка и команды — [ASSISTANT.md](../ASSISTANT.md).


## Исправление зацикливания генерации

После сообщения пользователя о цикле «супы-пюре-пасты» добавлены:

- Обзор «Что есть в меню?» по текущим строкам БД (`mode=facts`), с категориями, примерами и ценами. Работает и без Ollama.
- Проверка повторяющихся n-грамм в ответе; при цикле используется безопасная выдержка из источников (`mode=sources`). Такие ответы не возвращаются в историю промпта.
- Более короткий контекст из найденных источников, два последних сообщения истории, окно 8192 и repeat_penalty=1.15.
